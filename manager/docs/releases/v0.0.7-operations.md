# 0.0.7 运维与验收合同

本说明描述 `v0.0.7+stable.20261105.1` 的预期合同，**不是已经部署或以后永不故障的证明**。部署结果、完整门禁和观察窗口由独立签名发布及验收回执给出。此次授权窗口为北京时间 2026-11-05 04:30，不提前切换，门禁未通过则保留原服务。

## 所有前序候选一起合并

包含先前 0.0.7 的兼容规则、有限回退、跨语言续期锁、短预算推理、日志先归档后删除、v2 证据健康、只读 unknown 队列、目录并发合并、就绪竞态修复与智汇发布中心；保留当前 0.0.6 `.4` 的钱包取消关闭修复、密钥吊销和配对恢复边界。钱包及配对恢复核心文件必须与现网基线逐字节一致。

## 重试与提示词

- 11 条版本化兼容规则只处理 WorkBuddy 的 system/developer 文本，可关闭并支持经验证的热配置。用户、助手、工具正文、JSON 参数、图像均不改写，不进行数字 11128 全局替换。
- 11128 必须结合渠道文案和结构分类；稳定拒绝不得伪装成功，也不得引发全局提示词降级或账号连坐。
- 每个 Manager 执行最多 8 次供应商发送授权，跨账号、路径、gzip 与 Manager 再次 dispatch 共用。授权计数不等于供应商已处理或已收费，账务仍以供应商证据为准。
- 禁止供应商 Chat POST 自动跟随重定向，防止绕过发送计数或把已接收正文再次转发。客户端另行发起的新 HTTP 请求是独立执行，不宣称把多个独立客户端请求合并为同一个预算或自动幂等。
- 剩余总时限由 Manager 传给引擎，最大 600 秒；客户端取消仍沿上下文关闭。计数回执缺失或异常则停止后续拒绝重试，不能利用错误信息不足扩大重放。
- 只有可证明未发送或明确未处理的拒绝允许有限重试；已输出、已接收但处理情况不明、断流不自动重放。

## 页面与积分

账号页先读本地快照，不等待上游积分查询才显示列表。自动刷新只处理过期或缺失项，每次至多 64 个，失败退避 60 秒，沿用已有并发限制和凭据级单飞；手动全量刷新保留。旧快照会明确保留缓存身份，未知不改成零，不据此更改钱包或账号健康。

未变化 JSON 在深度 32、节点 100000 的边界内复用引用。超过边界直接采用新值，不丢弃变化、不保留旧分组。100/500/2000 行是合成浏览器逻辑测试，不是现网供应商吞吐或首字承诺。

沿用现有按密钥轮转的有界准入队列，不新增第二层排队、不扩大并发默认值。公平性、取消、排空及字节限制由原测试和此次全量门禁验证；没有测量证据时不打开账号软偏好、大请求分散或额外调度算法。

## 观测和协议边界

- 保留既有指标名，新增 `zhihui_failure_families_total`，标签只允许有限协议、流量类型和固定错误族，不带提示词、账号或错误正文。
- readyz、HTTP 可达、鉴权、模型授权、额度、渠道与流完整性是独立事实。裸 11128 保持未细分，HTTP 200 但无正常完成不冒充成功。
- `GET /api/system/protocol-contracts` 需要现有登录身份，说明当前 WorkBuddy 适配能力；不是供应商原生保证。Responses 历史、后台任务、strict 工具和串行工具保证仍明确拒绝，不新增状态服务。
- `python deploy/protocol_contract_diff.py BEFORE AFTER` 仅检查智汇 contract-v1 的路径和已支持能力移除，不是完整 OpenAPI 检查。发现破坏变更退出 2，输入无效退出 1。
- `python deploy/upstream_review.py --observed SNAPSHOT.json` 只比较离线公开提交身份；不联网、不执行上游代码、不自动安装。未观察到的项目标为 unknown 并退出 2，不解释为仓库已删除。
- 合成回放夹具与 Fuzz 不含真实用户会话、凭据和可执行命令；客户端版本未知明确写 null，实际客户端验收单独记录。

## 发布和回滚

必须先隔离 Linux 执行全量门禁、核对输入哈希及运行闭包、验证签名与新容器身份，之后准备本地可恢复备份，再以可信协调锁 fence/drain、停止写者并切换。没有通过门禁、排空超时、身份不符或恢复条件不成立时停止，不强制结束正在使用的请求。

切换后验证发行身份、前端静态资源、readyz、账户池、三协议小额调用、流完成、工具闭环、取消、钱包与事件采集；确认后再同步 GitHub。回退只切代码、前端和引擎，**不恢复旧业务数据库、不重新启用已吊销密钥、不重置消费和 unknown**。

弱口令、管理员、会话和权限依用户要求不在本轮变更中。暂不加入售卖、费用运营、媒体或高级 Responses 状态服务，不上传任何业务备份。
