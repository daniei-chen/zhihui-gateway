# 智汇产品更新日志

从 0.0.2 开始，只记录智汇自己的发版。继承组件与早期整理稿移入历史归档，
不作为当前产品版本列表，也不影响调用记录、额度或计费账本。

## [0.0.2] - 2026-10-29

### 新增

- 首页、登录页和控制台共用蓝色 Z 标识与蓝白品牌语言，网站图标同步换新。
- 系统更新展示智汇版本、固定源码仓库和实际源码提交，升级来源统一为自己的仓库。
- 按密钥增加缓存命中率和输出 tok/s，按模型增加缓存命中率；没有可靠数据时显示 —。

### 改进

- 首页恢复居中首屏、悬浮 Z 和全部章节，压缩文案；蓝色光路、粒子、账本回执与工作台切换各有细节。
- 控制台每个管理页面左上角显示蓝色 Z 和完整“智汇网关”；冰蓝通透卡片与首页同系，保留按钮及原有操作。
- 保留浮动 Dock、悬停与拖动、明暗主题和五种界面语言，适配手机与桌面。
- 用量页聚焦用量趋势、按模型和按密钥，不再默认展示上游累计统计和技术诊断证据。
- 按密钥列表不再显示已删除密钥留下的纯数字行；历史用量仍计入总量，账本不删除。
- 首页预览由同一份真实控制台构建生成，桌面与手机分别渲染；仅使用隔离合成数据。
- README 纳入真实首页、控制台效果与清晰的开发、升级和回退边界。
- 更新日志从智汇自己的版本线重新开始，不再混入继承组件的发版记录。

### 安全

- 渠道校验拒绝单独给出简明提示与请求编号，不重试、不绕过渠道限制，也不据此停用账号。
- 受控安装保留签名、完整测试和可信发布保护，不通过网页直接覆盖运行代码。
- 继续保留未知用量与待核对状态，不因请求失败就将费用归零或自动判定账号失效。

### 说明

- 缓存命中率按已上报的缓存命中与未命中 Token 计算；输出速度基于成功请求的生成耗时估算，只覆盖仍保留的日志样本。
- 已删除密钥的历史用量保留在总量与按模型统计中，因此当前密钥列表之和可能小于总量。
- 回退只恢复代码和界面，不恢复旧数据库、额度、授权或会话撤销状态。
- 长期稳定性、真实供应商长尾和离机灾备仍需持续验收，本版不代表所有审计问题已关闭。
