# 0.0.6：自用稳定版

本版本集中改善 WorkBuddy 客户端兼容、流式连接、调度、诊断及发布可核验性。已有钱包、密钥权限和历史账本保留；新增售卖、补贴运营工作台、有状态 Responses、媒体及新供应商功能暂缓。

## Codex 与 Claude 的特定模板兼容

普通 API 成功而编码客户端失败，曾复现为 WorkBuddy 对特定系统模板返回 11128。Codex 已验证的规则在 `You are a coding agent running in the Codex CLI` 的 agent 后补一个逗号；Claude 规则处理已验证的身份句、计费头提示、反馈句及分支提示。规则来自固定证据，不把所有上游拒绝视为可改写问题。

0.0.5 的现网临时规则现已收进 [版本化规则包](../server/workbuddy-compat.json)。新部署默认带规则。仅处理 WorkBuddy 的 system/developer 文本；用户、助手、工具参数与结果、图片及其他供应商不参与。每次请求记录包版本与命中 ID，不记录提示词原文。已有自定义规则仍优先；将 `prompt_compat_enabled` 设为 false 可即时关闭，随后请求生效。

明确拒绝继续返回失败；发送已被接受或是否被接受未知时，不为适配模板重新发送。

## 状态与流式连接

- 预流式 HTTP 400、401、403、429 保留其状态；HTTP 200 后的协议或传输失败仍明确计为失败。
- 历史“记录 502、实际 HTTP 400”的行在日志读取时解释为实际状态，同时提供原始状态。历史事实及消费记录不重写。
- `WB_SSE_HEARTBEAT_SECONDS` 默认 15 秒，合法范围 1–60，0 关闭。输出为 SSE 注释，不是模型内容、工具事件、首字或完成标志。
- 心跳由单一写入方串行输出；关闭时回收其持有的读取任务。心跳不延长上游读超时、不推导零用量，也不重放供应商请求。

## 容量与原生协议

容量队列最多 64 项、每密钥最多 4 项，按密钥轮转、同密钥内部 FIFO。`WB_GATEWAY_QUEUE_WAIT_MS` 默认 1000，范围 0–5000，0 恢复立即容量拒绝。排队期间不读取请求体、不领取上游账号；已有每密钥并发检查仍生效。队列满或等待超时返回 503/Retry-After，未发送至供应商。

`upstream.protocol_profile` 支持空值或 `legacy-v1`，以及 `desktop-5.9.3`；未知配置拒绝启动。后者协调 WorkBuddy 5.9.3、CLI 2.165.0 和 local-agent 标识，限定在已识别的 HTTPS 原生主机及默认端口；显式客户端、CLI 和 UA 配置仍优先。自定义中转主机保留旧配置。这是固定版本配置，不宣称自动追踪供应商最新版本。国内与国际账号的品牌及路由仍分别处理；生产国际账号未配置时，只能声明合成回归覆盖。

## 模型与监控口径

模型元数据新增明确声明的 `default_context_length` 和 `context_length_options`。默认预算与能力上限分别展示；无声明则省略，不根据上限推算默认值。无可靠上下文数据时省略能力值；已有注明来源的静态目录仍可作为补充。矛盾的默认值被省略并标记冲突。

监控计数自当前进程启动起累计；重启是合法 counter 重置，删除日志不重置。近 1 小时和 24 小时为有界分钟桶 gauge，覆盖不足由 `workbuddy_metrics_window_coverage_seconds` 明示，不能冒充完整历史。延迟分位保留最多 20000 项；模型标签最多 64 种，其余合并为 other。成功率应按 inference 流量与逻辑状态计算，探针、管理操作和取消另看。首字只统计有效模型内容，心跳不计入。抓取只读取这些有界内存结果及准入水位；认证仍是强制的。

公开 `/api/readyz` 只返回后台健康结果的一位状态；缓存过期、健康失败或排空时返回 503，不为匿名探测逐次执行写入。

## 凭据、恢复及发布

账号凭据导出要求 15 分钟内重新登录的管理员本人会话，普通 API token 无法导出。会话自动续期不重置这段认证时间。

发布前备份、严格隔离门禁、最终签名制品及执行权限检查、双账本隔离恢复与实际运行验收是独立步骤。测试通过不等于已切换；代码回退不恢复业务数据库，不恢复已失效的旧内部连接密钥。兼容诊断使用记账回执的可选附录，0.0.5 可忽略该附录并重放原有记账事实。

固定构建的验收数字、真实维护窗口、生产国内账号验证及未覆盖部分由随发布提供的机器回执记录。没有真实断电、长期 SLO 或完整全新主机灾难恢复证据时，不作相应承诺。
