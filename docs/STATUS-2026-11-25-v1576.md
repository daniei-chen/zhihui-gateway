## 2. 前端产物是从上一版借的，但版本显示没受影响

这版只改了后端两个文件，`web/out` 直接从 `releases/v1.5.75/web` 打包复用。
按经验这会导致前端显示旧版本号，所以专门查了它从哪读。

**结论：不依赖构建产物。**

- `web/lib/product.ts` 里的 `PRODUCT_VERSION = '1.5.76'` **全仓只有定义处一处引用** ——
  它只是 §2.4「六个版本面」要求同步的一项，不是 UI 的数据源。
- 实际显示走 `ChangelogPanel.tsx`，数据来自 `systemApi`（服务端 API），
  版本号与更新日志都是**运行时**取 CHANGELOG 与发布信息。
- `ChangelogPanel.tsx:149` 的 `v${version}` 里的 `version` 也来自该 API 返回。

**所以复用旧 `web/out` 是安全的。**这一条值得记下来：以后只改后端时不必重建前端，
但**必须先确认这一点**，不能默认「反正后端改了前端无所谓」。
