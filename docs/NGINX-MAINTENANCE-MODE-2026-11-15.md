# nginx 维护模式：一次生产登录全挂的复盘 — 2026-11-15

**结论：这不是代码缺陷，是「开关打开了没有关」。但它暴露了三个真问题。**

---

## 一、发生了什么

**21:07–21:15，管理端所有人无法登录**，页面显示「服务暂时不可用，请稍后再试」。

同一时间：

| 路径 | 状态 |
| --- | --- |
| `/v1/*`（模型调用） | **正常** |
| `/healthz`、`/login`、`/dashboard/` | **正常** |
| **`/api/*`（管理端登录与操作）** | **全部 503** |

## 二、根因

`/etc/nginx/sites-enabled/zhihui.kaogong.art` 的**第 18 行与第 530 行**：

```nginx
# zh-container-maintenance-v1
if ($uri ~ ^/(api|qoder|trae|wb|workbuddy|zpush)(/|$)) { return 503; }
```

**这两行写在 `server` 块最前面，早于所有 `location`。**

所以写在它们下面的这些精心配置：

```nginx
location = /api/login        { limit_req ...; proxy_pass http://zhihui_mgr; }
location ^~ /api/portal/     { limit_req ...; proxy_pass http://zhihui_mgr; }
```

**一条都没机会执行**。nginx 在 `server` 级 rewrite 阶段就返回了 503，而那个 503 是 **nginx 自己的 HTML 页面**，不是应用的 JSON。

**前端只能把它显示成「服务暂时不可用」** —— 因为响应体里没有任何结构化的原因。

**从写入到撤销：七分钟。但用户在这七分钟里得到的信息是「服务挂了」，而不是「正在维护」。**

## 四、恢复做了什么

1. **备份**：`/root/nginx-zhihui-maintenance-rollback-20261115-211701.conf`
2. **注释掉两处开关**（保留原内容便于审计）
3. `nginx -t` 语法检查通过
4. `systemctl reload nginx`（**平滑重载，未中断连接**）

**没有重启任何服务，没有动代码，没有动数据。**

## 五、真问题一：开关没有自动关闭

**「开启」有代码路径，「关闭」是人工步骤。**

一旦操作者中途离开、或者以为它会自动恢复，**整个管理端就静默地一直 503**。

**这类缺陷的特征和之前那个清理服务一样**：不影响数据面，所以不会被任何面向用户的检查发现。

## 六、真问题二：症状指向了错误的排查方向

「服务暂时不可用」读起来像**后端挂了**。

实际排查顺序是：进程状态 → 登录失败计数表 → 审计表 → 数据库表结构 → **最后才对比「本地 401 / 公网 503」**，才定位到 nginx。

**本地正常、公网异常**这个对比是决定性的 —— **它把「应用问题」和「入口问题」分开了**。下次遇到同类现象，这是第一个该做的对比。

## 七、真问题三：503 响应没有携带原因

nginx 返回的是通用 HTML，**没有任何字段说明「这是一个计划内的维护」**。

用户看到的是故障提示，于是他来问「为什么服务不可用」——**而系统明明知道自己为什么拒绝**。

## 八、建议（待决定，未实施）

| 方案 | 作用 | 代价 |
| --- | --- | --- |
| **A. 维护开关加自动过期** | 靠时间兜底，避免忘记关 | 需要定时清理机制 |
| **B. `/healthz` 报告维护状态** | 排障时一眼看出「是维护不是故障」 | 改健康检查语义 |
| **C. 维护 503 加响应头**（如 `X-Maintenance: 1`） | 前端可显示「系统维护中」 | 改 nginx + 前端 |
| **D. 只写进发布检查清单** | 无代码改动 | 依赖人的记性 |

**倾向 C + A**：**让用户看到真实原因，同时让它自己会恢复。**

## 九、这份文档的用途

**下次看到「管理端 503、数据面正常」，先查这两行 `if`，不要先查应用。**

命令：

```bash
grep -n 'zh-container-maintenance' /etc/nginx/sites-enabled/zhihui.kaogong.art
```

**两行都在注释状态才是正常的。**
