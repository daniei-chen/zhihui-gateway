# 智汇 0.0.7：兼容、恢复与受控发布的统一升级

0.0.7 合并此前所有已验候选及本轮优化，不另起一个混淆的组件版本。公开提交与现网签名构建分别留证；GitHub 标签不是可以直接覆盖现网的安装包。

## 这次解决什么

| 链路 | 处理 |
|---|---|
| Codex / Claude / DSH | 11 条版本化系统/开发者模板规则；用户、助手、工具 JSON、结果与图像保持原义。兼容可关闭，不假装获得供应商授权 |
| 11128 | 渠道文案与结构联合分类，包括短文案 unapproved channel；裸 11128 不一概归渠道，不连坐账号、不全局替换提示词 |
| 重试与断流 | 每个 Manager 执行共享 8 次发送授权，覆盖账号、路径、gzip 与 redispatch；计数缺失即不继续拒绝重试，禁止 Chat POST 跟随重定向，已接收不明/已输出不重放 |
| 凭据 | Go / Python 单飞、同一内核锁、身份与代次校验及原子保存；原代理、权重和未知字段保留 |
| 页面 | 本地缓存先呈现、过期积分按需查询、自动单批 64、失败退避；有界结构共享避免重复替换未变数据 |
| 记录与账务 | 先归档并核验再按具体行删热日志；不可变证据和未决关联保留；unknown 不等于零消耗，也不等于钱包冻结 |
| 可观测性 | 低基数错误族、v2 证据新鲜度、只读核对与分层历史诊断；可达、就绪、鉴权、额度、渠道和流完整性分别表达 |
| 更新 | 智汇发布中心独立身份与匹配回执；旧网页安装退役，旧展示历史私有归档；签名、全量门禁、备份、排空、切换、验收后才发布 |
| 上游学习 | 39 项公开来源离线漂移检查、自有能力合同、版本化合成协议夹具与 SSE Fuzz；不自动下载或执行外部更新 |

发送授权不等于供应商已经处理或收费。客户端独立新发起的 HTTP 请求有独立预算，不声称跨多个客户端请求自动幂等。600 秒是总时限上界，不是首字延迟承诺。

### 现网验收覆盖什么

公网 HTTPS 实测使用 /v1/chat/completions、/v1/responses 和 /v1/messages，覆盖 Codex、Claude、DSH 的合成模板、三协议流式终态、Chat 与 Responses 的工具数值 JSON / 结果往返、取消不重放、拒绝不支持语义及证据健康，共 30 项检查。没有执行真实工具命令，也不把模板协议验证说成测试了所有客户端二进制。

Magpie 本机的 /backend-api/codex/responses 是客户端桥接入口，不是本部署网关公开 API。网关接收桥接后的 /v1/responses；不应把本机桥接路径直接拼到网关域名后。首次公网验收脚本曾错误使用该路径并收到 HTML，错误回执保留，修正为真实网关协议路径后重新完整验收。

本次切换期间，既有固定启动守卫在执行应用前拒绝过一次启动，自动重试后准入；原始 systemd 计数为 1，没有清零。验收单列该记录，并要求其后同一应用 PID 连续观察、计数不再增加。日志未记录具体拒绝分支，不能臆测原因，也不能宣称从未发生过启动失败；后续安全诊断码需要独立审核宿主信任闭合，不在现网原地修改启动器。

## 仍然保留的边界

Responses 为无状态适配；previous_response_id、后台任务、strict 工具 schema 和串行工具保证仍提前明确拒绝。没有新增售卖、费用运营、媒体及高级状态服务，现有钱包、历史账本与权限保留。默认不启用账号软下限或大请求分散，不在原有公平准入队列外叠加一层新队列。

代码、前端和引擎可受控回退，**业务账本不回退、已吊销密钥不恢复、未决不清零**。备份仅本地保存；不能仅凭完整性校验宣称整机容灾完成。

### 打包时保留真实前端构建身份

Next 导出会留下一个原生 build ID 空目录；仅收录文件的 tar 再打包会丢失它。正确做法是每一轮归档、重签打包和解包都保留目录条目，再验证归档往返、真实 Flight 身份和完整资产池准备。**不能在保留的 _next/build-id 空目录放 marker 文件**，这不属于允许的 static 资产域；两个检查阶段都必须保持严格，不能改校验器放行。

源码构建可运行 python tools/materialize_static_namespace.py --web src/three-platform/web；默认只读，--apply 只能在签名前创建与原生 BUILD_ID 一致的空目录，归档仍必须保留该目录。工具不代替可信发布器的签名、Flight、完整池准备或测试门禁。旧无效候选未获得正式发行，修正候选重新签名并重跑完整 Linux 门禁。
