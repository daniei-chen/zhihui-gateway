## 本轮吸收

- **国内模型展示名**：在现有地区、密钥白名单、官方目录裁剪之后，移除展示用 `cn:` 前缀；`global:` 保留，旧 `cn:` 调用仍由现有规则接受。重复模型只保留一个，优先字段更完整的条目；不改变转发、价格或调用权限。
- **工具命名空间**：接受 `tools`、`children`、`functions` 子字段以及有子字段的省略类型容器，保留本地完整命名空间和同名消歧。最多四层，超深请求在转发前返回错误，而不是照搬上游静默丢弃；动态加载工具也经过同一检查。
- **积分汇总行**：在现有 `Accounts` 明细中出现带包标识的明细时，仅移除已识别的无标识分类汇总行。数值型包标识（包括 0）仍算明细；两个余额相同的真实包不合并；总额和到期批次共用过滤结果。不将 Trae 的递归扫描和新账单接口整套移植到旧接口。
- **可部署测试闭包**：退役验签命令的拒绝入口也随 Manager 包发布，测试不再依赖部署包之外的仓库工具目录。Compose 缺失测试直接测试重建步骤，不以放宽受控更新拒绝规则使测试通过。
