## 延迟的实际边界

页面优化减少重复读取、跨平台串行等待和钱包写锁争用；本地测试不是生产 P95。模型首字还受输入大小、上传及供应商预填充影响。大型上下文的上传和供应商等待必须分开测量，不能把缓存命中解释为零处理成本，也不能静默删减用户上下文或放松 FULL/fsync 来提速。

网关支持受限 gzip 请求解压；客户端可通过 `manager/client/zhihui_upload.py` 在有明显收益时压缩同一 JSON 内容。是否能减少真实上传等待须在该客户端测量，不承诺所有 Codex / Claude 客户端都支持自动压缩。不会擅自更改用户其他客户端或 Harness 的个人配置。

## 发布失败临时回执

`.receipt-*.tmp` 代表发布中或发布失败时留下的费用证据；目录不可核实、未处置冲突或临时回执都会阻断新生成。运维不得直接删除这些文件、清空 unknown 或拿旧数据库覆盖现库。应先停止相关写入并保存完整本地备份，检查回执 schema、执行 ID、归属与主库已提交事实，再使用受审恢复流程核对；死信处置必须记录操作人、原因及证据。
