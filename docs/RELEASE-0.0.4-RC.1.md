# 智汇 0.0.4 用户工作台源码预发布

本版标签为 `v0.0.4-rc.1`，产品版本为 `0.0.4`。它是本地候选的源码预发布，不是线上部署回执，不替换GitHub正式最新版 `v0.0.3`，也不是已经通过完整稳定运行验收的安装包。

## 新用户功能

- `/portal` 是独立用户入口，由总台 `/members` 开通用户，不开放公开注册，不授予管理员权限。
- 用户可扫码添加WorkBuddy国内个人账号，查看绑定数量、初始积分、签到、到期批次、流水、密钥与分页请求记录。扫码使用官方授权；本轮供应商行为仅用本地夹具验证。
- 初始积分沿用核实后的原到期时间。每日签到确认到账100积分，每批最长30天独立过期，不在第30天清空后来领取的全部积分。总台代签、用户手动和默认关闭的自动签到共享状态。
- 用户贡献账号进入公共池，消费归属用户自己的钱包；仅允许指定DeepSeek国内模型，不按贡献者的账号独立选池。本版没有新增IP限制。
- 可用额度为0时提示“额度已用尽，请联系管理员赠送额度”。不支持信用、未来签到预支或自动借款。仅用户名admin且角色admin的本人会话可赠送实际积分；赠送有效期、原因、操作者和重复提交保护独立记录。
- 总台可重置用户密码，旧会话和旧代次调用密钥失效，积分与账号保留；用户重新登录后可创建新密钥。重置成功清除密码失败锁定，普通管理员、用户凭据及管理Token不能借此提升权限。

## 计费调用尚未开放

用户钱包保留积分，但用户计费请求返回明确的暂未开放提示。原因是现有上游没有已核实、可强制执行的单次积分费用上限；Token限制、超时、冻结余额或取消并不能保证供应商账单不超过钱包。

本版采用拒绝发送的保护，没有环境变量或管理按钮绕过。不能把“事后记欠额”当成不透支方案。现有管理端密钥策略不因此改成用户钱包策略；赠送也不向供应商充值、不创造公共池真实余额。

## 升级与异常恢复

受控实例停用旧式网页上传/自助安装，旧独立验签入口退役；历史包存在不代表已获发布批准。不新增可绕过受信发布器的快捷安装路径。

费用未知不按TTL自动解冻。请求结束凭证绑定用户、密钥、请求与worker；清理超时或失败不生成结束凭证。管理员人工核对仍需要真实费用证据，不能仅凭HTTP返回或进程存活状态猜测零费用。

双库、身份、凭据和回执支持离线配对快照及全新目录隔离恢复。恢复副本禁用密钥、撤销旧会话、关闭自动签到并封存凭据，旧余额不可直接重新消费。恢复中途失败留下的半成品严禁运行；工具不覆盖现有业务数据。

## 使用与部署边界

- GitHub源代码不包含生产数据库、账号凭据、私钥、运行回执或供应商源码归档。源码提交和GitHub摘要不替代既有受信签名。
- 正式部署仍要求精确提交构建、Linux完整门禁、角色与账本兼容、受信签名和独立发布审批；不要执行旧安装模板覆盖现有服务。
- 真实扫码、签到、模型计费、全部writer停止证明、Linux文件权限/崩溃、离机备份及长期运行仍未验收。不把当前Windows专项通过声明为这些门禁完成。
- 既有64项审计工作包没有因本次版本号而全部关闭。本版只包含已经纳入候选的修复与新用户功能，历史未关闭问题继续保留。
