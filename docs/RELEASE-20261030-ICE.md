## Trae 问题原因与使用边界

旧 Manager 回调参数白名单漏了上述两项，导致实际官方回调在授权码交换之前返回 400。
已用全合成、同结构回调复现原错误并新增回归测试；没有复用用户在聊天中贴出的授权码或个人信息。

授权链接在用户浏览器打开时，回调 `127.0.0.1` 指向用户设备，不指向生成链接的 Linux。
当前仍是“官方页面授权 → 复制完整回调 → 粘贴智汇 → 后台提交交换”的手动模式，
不是服务器浏览器自动接收。浏览器提示 loopback 无法连接与 Manager 参数校验报错是两个问题。

发布会重启 Manager 并更换授权适配器代次；请重新发起授权，不使用旧窗口、过期或公开过的回调。
真实供应商兑换与账号入池仍须用户本人测试；本次不把合成验证写成真实授权已通过。
