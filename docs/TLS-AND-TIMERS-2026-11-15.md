## 三、续期是自动的

| 项 | 值 |
| --- | --- |
| 机制 | `certbot.timer`（systemd 定时器） |
| 频率 | 每天一次 |
| 上次运行 | 2026-11-15 12:18 |
| **下次运行** | **2026-11-16 11:43** |
| 备用 | `/etc/cron.d/certbot` 也在 |

**到期前一个月，每天会自动尝试续期** —— 不需要人工介入。

**但有一件事值得记住**：**自动续期成功之后，还需要 web 服务重新加载证书**。
如果续期成功而服务没重载，证书文件是新的、对外提供的还是旧的。
`certbot` 的续期钩子通常处理这件事，**但这个钩子是否配置正确，我没有验证**。

**验证方法**（在下次续期后做）：比对证书文件的修改时间与线上握手拿到的到期时间。
如果文件已更新而握手仍是旧日期，就是钩子没生效。

它检查的四项是：磁盘、`kaogong-api` 服务、`nginx`、站点可达 ——
**没有一项覆盖智汇网关自己的进程**。
