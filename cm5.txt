docs(changelog): 1.5.22-1.5.25 也改为发布清单风格

Releases 页面应该是升级说明，不是开发笔记。前几版写成「这一版源于今天一次
长达 10 小时的静默故障」「只要还有一个地方写死平台名，下线就只是半成品」
这类叙事 —— 读者关心的是升级了什么、修了什么、有没有兼容性影响。

本次把这四段统一改成清单式：新增 / 变更 / 修复 / 验证。
同时把 GitHub Release 标题里的叙事副标题去掉，只留版本号。

保留：影响面、兼容性说明、验证数据。
删除：排查过程、比喻、自我总结。

GitHub 上 v1.5.22 ~ v1.5.25 四个 Release 已同步更新。
