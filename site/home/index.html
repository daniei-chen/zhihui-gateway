SIMPLIFY THE COMPLEX

一个入口。
复杂的留给网关。

把分散在不同平台的授权资源，收拢到一个一致的管理体验。从 API 密钥到使用统计，再到账号健康，每件事都能找到清晰的位置。

多平台统一管理

集中查看 WorkBuddy、Qoder、Trae 的账号、模型与管理信息，同时保持各平台的数据与作用域边界。

权限不止一道门

按访问 Key、IP 规则、模型白名单等维度定义使用边界。凭证、额度与授权范围可在控制面统一治理。

调用与用量可追溯

在日志、统计和账本中理解调用表现。上游 usage 缺失时，保留 unknown 记录，不把未知消耗悄悄算成零。

BUILT WITH INTENTION

看起来简单。
背后每一步都算数。

比起堆砌功能，我们更关心边界是否明确、账目是否准确，以及系统是否能被安全地维护。

01 / ACCESS

先确认权限

有效的 API Key、允许的 IP 与模型范围，是请求进入网关的第一道门。

02 / ROUTE

再决定去向

按当前配置中的平台入口和上游策略转发，避免把不同来源的账号与数据混为一谈。

03 / RECORD

最后留下依据

记录调用状态与可获得的计量数据。无法确认的部分保持未知，留待后续核对。

ENGINEERING, NOT JUST A PROXY

看得见的轻盈。
看不见的严谨。

智汇仓库更重视可核对的计量、可理解的边界，以及有约束的发布和回退。把工程能力讲得准确，比堆砌空洞的性能数字更重要。

01

请求与账本

预算预留、结算与 unknown 记录，不把未知消耗自动归零。

02

构建与发布

以 Ed25519 签名和文件哈希为设计基础，实际是否生效由部署配置决定。

03

迁移与回退

优先兼容性扩展，降低数据库变更对旧版本的影响。

04

权限与审计

按 Key、IP、模型控制使用范围，管理操作需要独立鉴权。

PRIVATE BY DESIGN

保持开放的接口。
守住清晰的边界。

智汇是为本人及经授权用户而建立的网关管理平台，不是公开售卖 API 的开放注册服务。凭据和敏感配置不应出现在公开页面中。

阅读项目 README ↗
01

仅向授权用户开放

不承诺公开注册、售卖额度或面向公众的服务等级保障。

02

最小化凭据暴露

真实密钥应由受控界面提供；本页面所有代码示例使用明确的占位符。

03

真实数据才叫实时

控制台演示不冒充线上状态，实际账号健康、额度与请求量必须取自已授权的数据源。

不保证。实际模型列表和可用性受平台、账号授权、版本、额度与运行状态影响，以当前部署和相应权限下的接口结果为准。
